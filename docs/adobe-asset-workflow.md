# Adobe Asset Production Workflow

The target UX role values Adobe Creative Suite skills. This repository therefore defines where Adobe tools fit into a production-ready design-system workflow.

This document describes the intended workflow; the coded SVG/CSS assets in the repository are implementation artifacts and should not be misrepresented as files authored in a specific Adobe application unless they were actually produced there.

## Illustrator

Best suited for:

- master Cedarline logo / brand mark;
- scalable icon masters;
- vector illustrations;
- export preparation for SVG;
- checking path cleanliness before handoff.

Recommended deliverables:

- editable AI source;
- SVG exports;
- PNG fallbacks when necessary;
- icon grid / sizing documentation.

## Photoshop

Best suited for:

- image treatment standards;
- cropping and focal-point examples;
- tonal consistency across photography;
- web-optimized raster exports;
- examples of acceptable vs. unacceptable image manipulation.

Recommended deliverables:

- layered PSD examples;
- before/after image treatment samples;
- optimized JPG/WebP exports;
- documented crop ratios.

## InDesign

Best suited for:

- polished design-system reference document;
- printable / shareable standards guide;
- component-specification sheets;
- recruiting portfolio PDF.

Recommended deliverables:

- packaged INDD source;
- accessible exported PDF where feasible;
- linked vector/raster assets;
- master-page and paragraph-style usage.

## Portfolio integrity

Only list Illustrator, Photoshop, or InDesign as project tools if corresponding source work is actually created in those applications.

A next portfolio pass can add:

1. Illustrator brand/icon source;
2. Photoshop image-treatment board;
3. InDesign/PDF Cedarline standards guide.

That would make the Adobe evidence explicit rather than implied.
