# Content Standards

## Voice

Cedarline content should be:

- calm;
- direct;
- human;
- precise;
- non-alarmist;
- clear about uncertainty.

## Action labels

Use verbs and outcomes.

Preferred:

- Submit claim report
- Save progress
- Add documents
- Log contact
- View claim status

Avoid:

- OK
- Yes
- Go
- Submit (when the object is unclear)

## Insurance terminology

Use plain language before formal terminology when possible.

Example:

**Preferred:** “If someone says you caused injury or damage”  
**Then introduce:** “Personal liability coverage…”

## Optional information

Say when information can wait.

Examples:

- “You can add photos later.”
- “Exact time is optional.”
- “Choose Unsure if you do not know yet.”

## Confirmation

Do not imply a business decision the system has not made.

Example:

**Preferred:** “Your claim report was received.”  
**Avoid:** “Your claim is approved.”

## Errors

State:

1. what is wrong;
2. where it is wrong;
3. how to fix it when known.

Example:

“Enter an address, intersection, or general location.”
