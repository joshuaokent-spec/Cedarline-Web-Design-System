# Cedarline Web Design System

A **corporate web standards and reusable UI system** for the fictional Cedarline Mutual insurance experience.

**Design systems · Corporate web standards · Accessibility · Visual design · Responsive UI · HTML/CSS/JavaScript**

> Cedarline Mutual is fictional. This project is an independent UX portfolio case study.

## Project thesis

The first three Cedarline projects solve specific UX problems. This project asks a different question:

> **What shared standards should keep all Cedarline web experiences consistent, accessible, maintainable, and recognizable?**

The design system is intended to support both customer-facing and internal applications without forcing every product team to reinvent buttons, form states, focus behavior, spacing, typography, alerts, tables, or content patterns.

## Scope

The initial system covers:

- brand and semantic color tokens;
- typography;
- spacing, radii, and elevation;
- buttons and links;
- form controls and validation;
- alerts and status messaging;
- cards;
- tables;
- navigation;
- modal/dialog behavior;
- empty states;
- responsive rules;
- keyboard/focus standards;
- content standards;
- implementation guidance;
- governance and contribution principles.

## Research integrity

This is a portfolio concept, not a production design system deployed inside a real insurer. Standards are documented as a coherent design proposal and implementation exercise, not as the output of a real enterprise governance process.

## Planned case-study chain

Audit existing Cedarline patterns → define principles → create tokens → standardize components → document accessibility → define responsive/content rules → coded style guide → governance/handoff.
